# Evidence: check the connection that carries the claim

## Numbers

Trace a reported value to its source table, dataset, script output, or run. Check denominator, units, direction, sample, comparison, and uncertainty as relevant. Recompute from the supplied data when requested and feasible. If two sources conflict, identify their versions and the specific discrepancy before selecting a value.

Use exploratory and confirmatory labels from the actual design. A retrospective model fit, a held-out evaluation, and a prespecified test support different claims. Two groups having different significance labels does not establish a difference between their effects.

## Citations

Check that the source supports the particular claim, population, and method attributed to it. Verify bibliographic fields needed for the deliverable using the supplied source or an available retrieval tool. Use the environment's search capabilities; this skill requires no particular plugin.

When a source is unavailable, mark the exact unverified citation or fact. Complete the supported work and request only the information needed to finish. A plausible title, remembered DOI, or relevant abstract is insufficient to invent a specific result.

## Strength of inference

Use association language for observational associations. Explain mechanisms in proportion to direct measurements and design. A hypothesis can be useful when identified as such. An interval spanning the null expresses uncertainty; it does not establish equivalence. Report effect sizes and uncertainty when they are available and relevant.

Retain evidence that changes the main conclusion beside that conclusion. A brief result statement can be direct and appropriately bounded at once. State what was observed, under which design and conditions, and what it supports.

## Delivery

Present the supported result first. Include the specific source, unresolved discrepancy, or unavailable fact when it affects use of that result. Produce a full claim ledger or reference audit only when the task warrants one.
